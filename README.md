An Intelligent Fake News Detection System built using Machine Learning and Natural Language Processing (NLP) that classifies news articles as Real or Fake.
The application provides an interactive and user-friendly Streamlit web interface for real-time news prediction and analysis.

🚀 Features
🔍 Detects whether a news article is Real or Fake
🧠 Uses Machine Learning and NLP techniques
📄 Text preprocessing and cleaning
📊 TF-IDF Vectorization for feature extraction
🤖 Logistic Regression model for classification
🌐 Interactive Streamlit Web Application
⚡ Real-time prediction with high accuracy

Python
Machine Learning
Natural Language Processing (NLP)
Scikit-learn
